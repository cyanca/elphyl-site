プライバシーポリシー

最終更新日：2026年10月19日

取得する情報

ElPhyl は Google ドライブの drive.file 権限のみを使用し、ElPhyl 自身が作成または利用者が明示的に開いたファイルにだけアクセスします。それ以外のファイルや、氏名・連絡先などの個人情報は取得しません。

情報の利用と保存

メモの内容は利用者の PC と利用者自身の Google ドライブにのみ保存されます。開発者のサーバーへ送信することはなく、開発者がデータを閲覧することもありません。

第三者提供

取得した情報を第三者に提供・販売することはありません。

アクセスの取り消し

Google アカウントの「サードパーティ製のアプリとサービス」から、いつでも ElPhyl のアクセスを取り消せます。

Google API の利用について

ElPhyl による Google API から受け取った情報の利用と他アプリへの転送は、Limited Use 要件を含む Google API Services User Data Policy に従います。

Privacy Policy (English)

ElPhyl uses only the Google Drive drive.file scope and accesses only files it created or that the user explicitly opened with it. Notes are stored only on the user's PC and in the user's own Google Drive. No data is sent to the developer's servers or shared with third parties. Access can be revoked at any time from the Google Account settings. ElPhyl's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Contact: GitHub Issues
