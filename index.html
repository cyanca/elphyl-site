ElPhyl

ElPhyl は Windows 用の個人向け Markdown メモアプリです。メモを利用者自身の Google ドライブに保存し、スマートフォン用アプリ Elemi と同期します。

ElPhyl is a personal Markdown memo app for Windows. It stores notes in the user's own Google Drive and syncs them with the companion Android app.
